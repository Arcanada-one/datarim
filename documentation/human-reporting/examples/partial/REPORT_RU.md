**Выгрузка заказов.** Задача заблокирована: подтвердить весь требуемый результат пока нельзя.

## Что требовалось

Владельцу магазина нужна выгрузка заказов за выбранный период без доступа к данным других организаций. Пример синтетический.

Дать владельцу выгрузку только его заказов за выбранные даты.

## Что изменилось для пользователя

В учебной фикстуре выгружаются заказы за выбранный период. Владелец получает список за нужные даты.

## Проверка требований

Подтверждено **1 из 2** обязательных применимых критериев.

**В выгрузку попадают заказы только за выбранный период — Проверено.**
Проверяли: Проверить границы периода.
Среда: учебная фикстура.
В учебных данных границы периода соблюдены.

**Пользователь не может выгрузить заказы другой организации — Не проверено.**
Проверяли: Проверить запрос пользователя другой организации.
Среда: учебная фикстура.
Проверка под пользователем другой организации не запускалась.

## Где доступен результат

В рабочую среду не установлено.
Это учебный пример; рабочий магазин не изменён.

## Что мешает завершению и какие ограничения остаются

Изоляция данных организаций не подтверждена. До проверки публикация может открыть доступ к чужим заказам.

По плану не закрыты: Проверить изоляцию данных организаций.

## Что осталось сделать

Проверить выгрузку под пользователем другой организации. Ответственный: Разработчик.
