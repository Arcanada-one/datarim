# Datarim identity assets

These are the approved Datarim logos. Reuse this identity in repository documentation, websites and release communications; do not replace it with a typed initial, redraw it or recolor it.

- `original/`: the three supplied transparent PNG files, preserved without modification.
- `datarim-wordmark-light*`: dark lettering for light backgrounds.
- `datarim-wordmark-dark*`: white lettering for dark backgrounds.
- `datarim-icon-*`: the square mark for favicons, app icons and compact contexts.
- `manifest.json`: original hashes and generated asset dimensions, sizes and hashes.

Presentation copies remove only outer padding and stray edge fragments. PNG and lossless WebP copies preserve transparency and the supplied colors. Keep the aspect ratio, allow space around the mark, and provide an accessible Datarim label when the image is a navigation link. The framework README selects its wordmark with the reader's color preference.

The website keeps the matching asset set in `img/brand/`. Use its explicit `.dark` class to select the white-lettered wordmark; keep dark lettering on light backgrounds. Updating the identity requires replacing the approved original files and regenerating their derivatives together.
